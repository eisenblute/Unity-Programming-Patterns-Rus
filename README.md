# Шаблоны игрового программирования в Unity

Здесь находится подборка шаблонов (паттернов) программирования для Unity, которые взяты из книги «Шаблоны игрового программирования». Эти шаблоны очень полезны для поддержания порядка в вашем проекте по мере его роста, потому что они описывают лучшие практики и готовые решения для часто возникающих проблем.

Вам не обязательно использовать их все — относитесь к ним как к инструментам. Вы можете менять их реализацию под свои конкретные нужды. Некоторые паттерны (например, Update, Game Loop, Component) уже встроены в Unity, так что вы уже используете их, даже не замечая этого!

Шаблоны программирования можно разделить на следующие группы:

1. **Архитектурные.** Определяют общую структуру всего приложения. Пример: MVC (Model-View-Controller, модель — представление — контроллер).
2. **Шаблоны проектирования.** Более конкретны и локальны, чем архитектурные. Пример: Одиночка (Singleton).
3. **Антипаттерны.** Сборник шаблонов, которые программисты используют для решения проблем, но на самом деле *не должны* их использовать, потому что эти решения неэффективны и вредны. Пример: «Божественный объект» (God object) — им часто становится класс `GameController`, в который сваливают всё подряд, лишь бы игра работала. Проблема такого класса в том, что он быстро раздувается, его становится трудно поддерживать и отлаживать, потому что в него намешаны логически не связанные между собой куски кода.
