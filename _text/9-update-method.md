# 9. Метод обновления (Update Method)

Метод обновления обрабатывает один кадр поведения. Каждый объект, которому это нужно, должен иметь собственный метод обновления. При этом, каждый объект, с таким методом, вы должны хранить в какой-нибудь структуре данных (например, в списке), а затем в главном методе обновления проходить по объектам по очереди.

**Как это реализовать?**

Этот паттерн уже реализован в Unity в виде метода `Update()` — вы можете использовать его, если ваш скрипт наследуется от `MonoBehaviour`. Unity обрабатывает каждый вызов `Update` один за другим внутри своего главного метода обновления.

Вы также можете, вместо использования встроенного метода `Update` от Unity, реализовать свой собственный метод обновления. Для этого, нужно хранить все скрипты, использующие этот метод, в списке. Затем в каком-нибудь скрипте (например, в `GameController`) надо пройти по тому списку внутри стандартного `Update` от Unity, что будет вызывать каждый пользовательский метод обновления по очереди. Так, например, становится проще поставить игру на паузу — достаточно просто не проходить по этому списку, когда игра приостановлена. Пример такой реализации приведён в исходниках.
